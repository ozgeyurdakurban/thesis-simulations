# External data (not included)

`sim10_diederich_estimation.py` and `sim10b_diederich_profile.py` read
`data_external/diederich_etal_dataverse/data/WS_data_noIP_noMTID_panel.dta`, the within-subject panel of the replication
package of Diederich, Eckel, Epperson, Goeschl and Grossman, "Subsidizing Unit Donations: Matches, Rebates, and Discounts
Compared" (Experimental Economics, forthcoming). Download the package from its Harvard Dataverse record and unpack it
into this folder; the raw data are not redistributed here. Precomputed outputs are in `../data/diederich_*.csv`.
